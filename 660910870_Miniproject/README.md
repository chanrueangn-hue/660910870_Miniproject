# 📚 BookShelf Pro - Reading List Web Application

เว็บแอปพลิเคชันจัดการและติดตามรายการอ่านหนังสือส่วนตัว (Reading List Tracker) พัฒนาด้วย Node.js, Express.js (Backend) และ HTML/CSS/JavaScript Vanilla (Frontend) ครบองค์ประกอบ REST API แบบ CRUD

## 🌟 ฟีเจอร์หลัก (Features)
- **Dashboard Stats:** สรุปสถิติหนังสือทั้งหมด, กำลังอ่าน, อ่านจบแล้ว แบบ Real-time
- **CRUD Operations:** เพิ่ม, แสดงผล, แก้ไขข้อมูล/คะแนนรีวิว และลบหนังสือโดยไม่ต้องรีเฟรชหน้า (Single Page Experience)
- **Advanced Search & Filter:** กรองหนังสือตามสถานะการอ่าน หมวดหมู่ และค้นหาตามชื่อหนังสือ/ผู้แต่งผ่าน Query String API
- **Responsive & Modern UI:** ตกแต่งด้วย CSS Custom Properties ในโทน Dark Dashboard สวยงามและเรียบหรู
